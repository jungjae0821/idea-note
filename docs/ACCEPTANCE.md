# 요구사항 대응과 발표 검증

원본: 바탕화면 README.md, 「오프라인 AI 아이디어 도우미 — 기획 및 설계」. 2026-10-14 사용자 요청에서 Gemini 무료 모델로 변경했습니다.

## 구현 대응

| 원안 | 구현 | 검증 기준 |
| --- | --- | --- |
| S01 홈·모델 준비 | 키 미입력/입력 상태, 생성 시작, 보관함·설정 | 키가 없으면 설정 안내; 저장/기록은 키 없이 접근 |
| S02 주제·조건 | 프로젝트 아이디어 1개 고정, 필수 주제, 선택 조건 | 공백 주제 차단; 200/1,500자 제한; 수정 시 값 유지 |
| S03 결과 | 진행 상태·오류·재시도·재생성·선택 저장 | 중복 생성/화면 버튼 잠금; 빈 출력 저장 금지 |
| S04 저장 목록 | 저장한 항목만 최신 저장순 | 동일 기록 중복 저장 없음; 빈 목록 안내 |
| S05 상세 | 입력·조건·본문·생성 시각·모델 | 기록 상세에서 저장; 저장 상세는 읽기·조건 재사용 |
| S06 기록 | 성공 결과 전체, 최신 생성순 | 저장하지 않은 성공 결과도 남음; 재생성은 새 ID |
| S07 설정 | Gemini 키, 선택 Firebase 로그인, 팀 문의 주소 | 미설정/오프라인 안내; 데이터 동기화 없음 명시 |
| 기기 영구 저장 | IndexedDB | 트랜잭션 완료 후 성공 표시; 종료 후 재조회 |
| 오류 시 결과 보존 | 현재 결과 유지 + 기록/저장 재시도 | 쓰기 실패 시 성공으로 표시하지 않음 |
| 오프라인 생성 | **Gemini 요청으로 변경해 제공하지 않음** | 인터넷 없이 생성할 수 있다고 표시하지 않음 |
| 오프라인 조회 | 빌드 화면 캐시 + IndexedDB | 캐시 준비 후 네트워크 없이 새로고침·기록 상세 |
| 아이디어 외부 전송 금지 | **최신 요청에 따라 변경** | 생성 시 Google 전송과 무료 등급 데이터 정책 표시 |

## 팀이 확인할 순서

### 1. 최초 준비

- [ ] Node 22.13+ 설치 후 README대로 실행한다.
- [ ] 실제 발표용 카테고리를 확정한다. 현재는 프로젝트 아이디어 하나다.
- [ ] Google AI Studio에서 무료 프로젝트 키와 현재 사용 한도를 확인한다.
- [ ] 앱 설정에 키를 입력한다. 키 입력 상태와 실제 생성 성공을 구분한다.

### 2. 실제 모델 안정성과 품질

입력 예: 주제 `대학생의 자투리 시간을 활용하는 앱`, 조건 `2명이 4주 안에 구현, 무료 도구 사용`.

대역 응답 테스트는 실제 Gemini 품질·속도·무료 할당량을 검증하지 않는다. 허용 응답 시간과 기준 기기 성능 목표는 팀이 측정 후 확정한다.

### 3. 저장·기록

- [ ] 서로 다른 결과 6개를 저장한다.
- [ ] 저장하지 않은 결과를 포함해 성공 기록 8건을 만든다.
- [ ] 같은 기록을 두 번 저장해도 항목 수와 최초 저장 시각이 바뀌지 않는다.
- [ ] 탭을 닫고 같은 주소·브라우저에서 다시 열어 저장 6개/기록 8건을 확인한다.
- [ ] 모든 상세에서 입력 주제·조건·본문·생성 시각을 비교한다.
- [ ] 기록 상세의 `이 조건으로 새로 만들기`는 입력만 복원하고 자동 생성하지 않는다.

### 4. 오프라인·오류

- [ ] `npm run build` 후 `npm start -- --port 8787`로 실행한다.
- [ ] 온라인으로 연 뒤 설정의 `오프라인 조회 준비 완료`를 확인한다.
- [ ] 네트워크를 끄고 새로고침하여 저장 목록과 상세·생성 기록을 연다.
- [ ] 새 생성은 인터넷 필요 안내를 표시한다.
- [ ] 잘못된 키·키 없음·요청 한도·차단/빈 응답에서 실패 안내를 확인한다.
- [ ] 생성 버튼을 연속 눌러도 요청은 한 번만 실행된다.
- [ ] 생성 중 이동 버튼이 비활성화되고 실패하면 다시 활성화된다.
- [ ] 기기 저장이 차단되면 현재 결과가 유지되며 저장 재시도가 가능하다.

### 5. 선택 기능

- [ ] 실제 Firebase 프로젝트로 구글 로그인, 취소, 실패, 로그아웃을 확인한다.
- [ ] 로그인 전후, 계정 변경 후 기록이 동일 기기에 남는지 확인한다.
- [ ] 로그인 실패 시 핵심 기능에 접근할 수 있다.
- [ ] 팀 오픈채팅 주소를 등록하고 실제 문의 페이지를 연다.
- [ ] 네트워크 요청에서 인증·문의 경로에 아이디어 데이터가 포함되지 않는지 확인한다.
