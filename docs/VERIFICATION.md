브라우저 통합 검증에 사용한 대역 응답 서버는 작업용 디렉터리에만 있으며 제품·배포 소스에 포함하지 않습니다. `tests/core.test.mjs`도 Google 응답과 IndexedDB 대역으로 검증합니다. 제품에는 샘플 성공 응답이나 생성 실패를 성공으로 바꾸는 대체 동작이 없습니다.

`연결 없이 재조회`는 실제 테스트 서버를 정지한 상태의 오프라인 복원 검증입니다. 운영체제 전체 네트워크를 끈 검증은 아니며, 상단의 온라인 표시는 브라우저 `navigator.onLine`이 보고한 기기 네트워크 상태입니다. 캐시된 글꼴이 없으면 오프라인에서 시스템 글꼴로 표시됩니다.

## 실행 중 발견해 수정한 항목

- Windows의 npm 실행 래퍼 경로 문제: 실제 npm JS 진입 파일을 Node로 호출해 설치/빌드했습니다. README에 실행 대안을 기록했습니다.
- 실행 중인 빌드 서버의 파일 잠금: 해당 서버 종료 후 다시 빌드했습니다.
- 실패 결과 화면의 성공 문구: 결과가 없는 경우 재시도 문구로 분리했습니다.
- 오프라인 준비 알림: 화면에서 실제 캐시 항목을 확인한 뒤 준비 완료로 표시하도록 수정했습니다.
